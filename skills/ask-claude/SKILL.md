# Ask Claude Skill

This skill allows Pickle Rick to query Claude Sonnet (via Vertex AI) for coding tasks.

## Usage

Use the provided script:

```bash
python3 ~/.gemini/extensions/pickle-rick/scripts/ask_claude.py "Write a python function to..."
```

## Configuration

- **Project**: `switon-gsd-demos` (default)
- **Model**: `claude-sonnet-4-5` (default)
- **Location**: `global` (default)

## Philosophy

Use Claude for code generation. Use Gemini for reasoning and management.
